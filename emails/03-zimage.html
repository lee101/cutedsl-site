Z-Image Turbo is our flagship text-to-image pipeline built on the CuteZImageTransformer -- a custom diffusion transformer where every attention layer is replaced with fused Triton kernels.

How It Works

Standard diffusion models spend most of their compute in attention. CuteZImageTransformer fuses the Q/K/V projections, softmax, and output projection into a single Triton kernel, eliminating memory round-trips and cutting latency by 4x compared to the baseline Flux pipeline.

Key Optimizations

Fused Triton Attention -- Q/K/V projection, softmax, and output in a single GPU kernel. No intermediate memory writes.

torch.compile -- reduce-overhead mode compiles the full forward pass for maximum throughput.

NVFP4 Quantization -- optional 4-bit quantization via torchao on RTX 5090 for even faster inference.

Try It Now

Send a prompt with optional width and height (default 1024x1024):

curl -X POST https://cutedsl.com/api/service \
  -H "Authorization: Bearer {{.APIKey}}" \
  -H "Content-Type: application/json" \
  -d '{
    "service": "zimage",
    "prompt": "a futuristic city at sunset, cyberpunk style",
    "width": 1024,
    "height": 1024
  }'

Returns a JSON response with a image_url field containing the generated image.
