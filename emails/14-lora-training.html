What is LoRA?

LoRA is a parameter-efficient fine-tuning technique. Instead of updating all model weights (billions of parameters), LoRA injects small trainable matrices into specific layers. The result: your model learns your style or domain in minutes rather than hours, using a fraction of the compute, while the base model stays intact.

Full fine-tune: Update all ~3B parameters, needs 80 GB VRAM, takes hours
LoRA: Update ~4M parameters (0.1%), needs 16 GB VRAM, takes minutes

Train via API — $50 per Job

Upload your dataset, specify the base model and training steps, and CuteDSL handles the rest.

curl -X POST https://cutedsl.com/api/service \
  -H "Authorization: Bearer {{.APIKey}}" \
  -H "Content-Type: application/json" \
  -d '{
    "service": "lora-train",
    "model": "zimage",
    "dataset_name": "my-brand-photos",
    "train_steps": 1000
  }'

Parameters:

model Base model to fine-tune: zimage or chronos2
dataset_name Name of your uploaded dataset (images for Z-Image, CSV time series for Chronos-2)
train_steps Number of training steps (default: 1000, max: 5000). More steps = stronger adaptation.
