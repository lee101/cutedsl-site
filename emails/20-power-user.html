Power User Tips

Use Batch Requests for Throughput

If you're generating multiple images or forecasts, send requests concurrently. The API handles parallel requests per user — don't serialize what can run in parallel.

Set a Seed for Reproducible Images

Pass a seed parameter to Z-Image to get the same output for the same prompt. Useful for iteration and A/B testing.

{"service": "zimage", "prompt": "...", "seed": 42}

Monitor Your Credits

Check your balance programmatically so you can alert yourself before credits run out.

curl "https://cutedsl.com/api/balance?wallet={{.WalletAddress}}"

Review Billing History

See every charge and deposit with timestamps and service details.

curl "https://cutedsl.com/api/billing-history?wallet={{.WalletAddress}}"

Optimize Chronos-2 With Quantile Levels

By default Chronos-2 returns median forecasts. Pass quantile_levels to get confidence intervals for risk-aware forecasting.

{"service": "chronos2", "values": [...],
 "quantile_levels": [0.1, 0.5, 0.9]}
