Try It Now

Pass an audio URL to transcribe:

curl -X POST https://cutedsl.com/api/service \
  -H "Authorization: Bearer {{.APIKey}}" \
  -H "Content-Type: application/json" \
  -d '{
    "service": "stt",
    "audio_url": "https://example.com/meeting-recording.wav"
  }'

Returns a JSON response with transcription text and duration_seconds. Billing is based on audio duration.
