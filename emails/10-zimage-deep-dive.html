Z-Image Turbo is already one of the fastest text-to-image models available, but standard PyTorch attention is still the bottleneck. CuteZImage replaces the entire attention path with a custom CuteZImageTransformer built on fused Triton kernels. Here is what that means in practice.

The Problem with Standard Attention

In a typical diffusion transformer, attention involves separate kernel launches for Q/K/V projections, the scaled dot-product, softmax normalization, and the output projection. Each kernel launch incurs overhead, and intermediate tensors (the full attention matrix) consume significant GPU memory - especially at higher resolutions.

CuteZImageTransformer: Fused Triton Kernels

The CuteZImageTransformer replaces the multi-kernel attention pipeline with a single fused Triton kernel that handles:

1. Q, K, V projection from input hidden states
2. Tiled matrix multiplication with online softmax
3. Output projection and residual addition
4. Layer normalization (fused into the same kernel)

Because the full attention matrix is never materialized in global memory, peak VRAM usage drops substantially. The tiled approach keeps data in SRAM throughout the computation.

Throughput Gains

Fewer kernel launches, no intermediate memory allocations, and better GPU occupancy add up. On an A100, CuteZImage generates 1024x1024 images approximately 2.5x faster than the default attention path, with no quality degradation - the outputs are numerically identical.

from cutedsl import CuteZImageTransformer

# Drop-in replacement for the standard transformer
model.transformer = CuteZImageTransformer.from_standard(
    model.transformer,
    fuse_layer_norm=True
)
