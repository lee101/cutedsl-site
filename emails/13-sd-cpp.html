Not every inference workload needs a GPU. stable-diffusion.cpp is a pure C++ implementation of Stable Diffusion that runs on CPUs, mobile devices, and edge hardware — no Python, no CUDA, no heavyweight dependencies.

Why C++ for Diffusion?

No Python Runtime Single static binary. No virtualenv, no pip, no version conflicts. Deploy anywhere.
Cross-Platform Runs on Linux, macOS, Windows, Android, and iOS. ARM and x86 support out of the box.
Tiny Footprint The binary is a few MB. Compare that to a multi-GB PyTorch installation.
CPU Optimized SIMD-optimized kernels (AVX2, NEON) for fast CPU inference without GPU hardware.

GGUF Quantized Models

stable-diffusion.cpp uses the GGUF format (the same format behind llama.cpp). Models are quantized down to Q4, Q5, or Q8 precision, dramatically reducing file size and memory requirements while preserving visual quality.

Format Model Size RAM Usage
FP16 (original) ~6.5 GB ~8 GB
GGUF Q4 ~2.0 GB ~3 GB

How It Complements CuteDSL

CuteDSL's GPU pipeline (CuteZImage, CuteChronos2) is built for maximum throughput on server hardware. stable-diffusion.cpp fills the other end of the spectrum:

Edge deployment — Run image generation on IoT devices or embedded systems with no cloud dependency.
Mobile apps — On-device image generation for iOS/Android without server round-trips.
Offline/air-gapped — Generate images in environments with no internet access.

Together, CuteDSL's GPU pipeline and stable-diffusion.cpp cover the full range — from high-throughput cloud inference to lightweight on-device generation. Check the evals page for performance comparisons across hardware targets.
