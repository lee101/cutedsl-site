Try It Now

Send text and a voice ID to generate speech:

curl -X POST https://cutedsl.com/api/service \
  -H "Authorization: Bearer {{.APIKey}}" \
  -H "Content-Type: application/json" \
  -d '{
    "service": "tts",
    "text": "Welcome to CuteDSL, the fastest AI inference platform on Solana.",
    "voice": "af_bella"
  }' \
  --output speech.wav

Returns a WAV audio file. You can also request a audio_url in the JSON response instead.
