Build a Full App With the CuteDSL API

5 steps from API key to a working multi-model pipeline

Hey {{.WalletShort}},

This tutorial walks you through building a pipeline that generates an image, captions it, converts the caption to speech, and forecasts usage — all with the CuteDSL API.

Step 1 — Get Your API Key

Connect your wallet and grab your API key from the dashboard. All requests use it as a Bearer token.

import requests

API = "https://cutedsl.com/api"
HEADERS = {"Authorization": "Bearer {{.APIKey}}"}

Step 2 — Generate an Image With Z-Image

Call the zimage service to create an image from a text prompt.

resp = requests.post(f"{API}/service", json={
    "service": "zimage",
    "prompt": "a futuristic city at sunset, cyberpunk",
    "wallet": "{{.WalletAddress}}"
}, headers=HEADERS)

image_url = resp.json()["result"]["url"]
print(f"Image: {image_url}")

Step 3 — Caption the Image

Pass the generated image URL to the caption service.

resp = requests.post(f"{API}/service", json={
    "service": "caption",
    "image_url": image_url,
    "wallet": "{{.WalletAddress}}"
}, headers=HEADERS)

caption = resp.json()["result"]["caption"]
print(f"Caption: {caption}")

Step 4 — Generate Audio With TTS

Convert the caption to spoken audio using Kokoro TTS.

resp = requests.post(f"{API}/service", json={
    "service": "tts",
    "text": caption,
    "voice": "af_heart",
    "wallet": "{{.WalletAddress}}"
}, headers=HEADERS)

audio_url = resp.json()["result"]["url"]
print(f"Audio: {audio_url}")

Step 5 — Forecast Usage With Chronos-2

Feed your daily API call counts into Chronos-2 to forecast future usage.

resp = requests.post(f"{API}/service", json={
    "service": "chronos2",
    "values": [12, 18, 25, 30, 28, 35, 42],
    "horizon": 7,
    "wallet": "{{.WalletAddress}}"
}, headers=HEADERS)

forecast = resp.json()["result"]["forecast"]
print(f"Next 7 days: {forecast}")

That's the full pipeline — image generation, captioning, text-to-speech, and forecasting in under 30 lines of Python. Read the extended version on the blog for error handling, async patterns, and batch processing.
