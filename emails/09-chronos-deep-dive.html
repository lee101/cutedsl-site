Amazon's Chronos-2 is a powerful time-series foundation model, but out of the box it leaves a lot of performance on the table. CuteChronos2 is our optimized pipeline that delivers a 24x speedup with identical output quality. Here is how we did it.

1. Batch-Compiled Attention

The default Chronos-2 attention implementation processes sequences one at a time. CuteChronos2 rewrites the attention path to batch across forecast horizons, then wraps the entire module with torch.compile. This alone eliminates Python dispatch overhead and enables the compiler to fuse softmax, scaling, and dropout into a single kernel.

BEFORE

Sequential attention heads, eager-mode execution, Python loop per head.

AFTER

Batched multi-head attention, compiled into a single CUDA graph with zero Python overhead.

2. Fused MLP Layers

Each transformer block in Chronos-2 has two linear projections separated by a GELU activation. CuteChronos2 fuses these into a single kernel, cutting memory round-trips in half and improving arithmetic intensity. Combined with weight pre-packing, the MLP path runs roughly 3x faster in isolation.

3. torch.compile with reduce-overhead

We compile the full pipeline using torch.compile(mode="reduce-overhead"), which traces the entire forward pass into CUDA graphs. This eliminates kernel launch latency and CPU-GPU synchronization points that dominate small-batch inference.

from cutedsl import CuteChronos2Pipeline

pipe = CuteChronos2Pipeline.from_pretrained(
    "amazon/chronos-bolt-base",
    torch_compile=True,
    compile_mode="reduce-overhead"
)
forecast = pipe.predict(context, prediction_length=64)
