Text Chat Example

Send a messages array just like OpenAI-style chat APIs:

curl -X POST https://cutedsl.com/api/service \
  -H "Authorization: Bearer {{.APIKey}}" \
  -H "Content-Type: application/json" \
  -d '{
    "service": "gemma4",
    "messages": [
      {"role": "user", "content": "Explain how Triton fused kernels reduce memory bandwidth in transformer attention."}
    ]
  }'

Vision Example

Include an image URL alongside your text prompt:

curl -X POST https://cutedsl.com/api/service \
  -H "Authorization: Bearer {{.APIKey}}" \
  -H "Content-Type: application/json" \
  -d '{
    "service": "gemma4",
    "messages": [
      {"role": "user", "content": "What is shown in this image?", "image_url": "https://example.com/photo.jpg"}
    ]
  }'

Returns a JSON response with the model's reply text.
